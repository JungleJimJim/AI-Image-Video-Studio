# 1.15.2 — Always-visible model installation controls

The Models toolbar stays at the top of its scrolling panel, so **Install selected models**, model selection controls and the download estimate remain accessible throughout the catalog. The toolbar has an opaque background and wraps on narrower windows.

This patch changes the Models layout. A local SSD model-path setup is specific to the configured installation and is not a performance change distributed by this release. Generation recipes and memory safeguards are unchanged.
